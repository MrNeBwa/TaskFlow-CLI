# TaskFlow CLI

Мини-канбан-трекер с аналитикой спринта. Это консольное приложение, которое позволяет управлять задачами (подобно Jira/Trello), но прямо из терминала.

## Основной функционал
- Управление бэклогом и статусами задач (To Do, In Progress, Done).
- Назначение приоритетов и дедлайнов.
- **Sprint Analytics:** расчёт velocity (скорость команды), burndown chart (график сгорания задач), загрузка команды.
- Экспорт отчётов в различные форматы (JSON, CSV, HTML/Markdown).

## Стек технологий
- **C++17**
- **CMake** (Система сборки)
- **CLI11** (Парсинг командной строки)
- **fmt** (Продвинутое логирование и форматирование строк)
- **nlohmann/json** (Работа с JSON для сериализации задач и отчетов)
