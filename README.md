# TaskFlow CLI 🚀

![C++17](https://img.shields.io/badge/C++-17-00599C.svg?style=flat&logo=c%2B%2B) ![CMake](https://img.shields.io/badge/CMake-3.14+-064F8C.svg?style=flat&logo=cmake) ![License](https://img.shields.io/badge/License-MIT-green.svg)

**TaskFlow CLI** — это легковесный консольный канбан-трекер с поддержкой аналитики спринта, написанный на C++. Он позволяет бесшовно управлять бэклогом, отслеживать статусы задач, назначать приоритеты и дедлайны прямо из терминала. Результаты и метрики (velocity, burndown chart, загрузка команды) легко экспортируются в JSON, CSV или HTML для дальнейшего использования и визуализации.

---

## 🎯 Основной функционал
- **Управление задачами:** Бэклог, статусы (*To Do, In Progress, Done*), приоритеты и дедлайны.
- **Интеллектуальная аналитика:** Автоматический расчёт *velocity* (скорости команды), построение *burndown chart* и оценка загрузки команды.
- **Универсальный экспорт:** Генерация sprint-отчётов в форматах `JSON`, `CSV` и `HTML/Markdown`.
- **CLI-First дизайн:** Быстрый доступ к задачам без необходимости открывать браузер или тяжеловесные приложения (подобно Jira/Trello).

## 🛠️ Стек технологий
- **C++17:** Современный стандарт языка, использование STL (`vector`, `map`, `algorithm`), `std::chrono` для работы со временем.
- **CMake:** Гибкая система сборки проекта.
- **CLI11:** Удобный и прозрачный парсинг аргументов командной строки.
- **fmt:** Продвинутое логирование и быстрое форматирование текста.
- **nlohmann/json:** Сериализация данных, сохранение состояния и экспорт отчетов.
